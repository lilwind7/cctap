# cctap 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 cctap —— 一个通过 Homebrew tap 分发的 macOS 工具，监听 Claude Code 的 Stop / Notification / SessionEnd hook，弹出带项目名 + 用户消息摘要的原生通知横幅，点击可切回对应 Warp tab。

**Architecture:** 一个 bash 入口 `bin/cctap` 按 argv 分派到 hook handler / install / uninstall / doctor。`lib/` 下放小而独立的辅助函数（transcript 解析、Warp 焦点判断、Warp 切焦点、terminal-notifier 调用）。`share/install/` 下放 settings.json 的 jq 合并脚本和 hook snippet。所有 hook 路径强制 exit 0、不写 stdout、≤1s 返回。

**Tech Stack:** bash 4+、jq、terminal-notifier、osascript（用于 Warp 的 AppleScript 字典）、bats-core（测试）、GitHub Actions（CI）、Homebrew formula（分发）。

`lib/transcript.sh`：

```bash
# Extract the last user message from a CC transcript JSONL file.
# Echoes the message text (truncated to 60 chars + ellipsis) or empty string.
# Exit code is always 0.
extract_last_user_message() {
    local path="$1"
    [ -r "$path" ] || { echo ""; return 0; }

    # tac is GNU-only on macOS via coreutils; use awk reverse instead.
    local msg
    msg=$(awk '{ lines[NR] = $0 } END { for (i = NR; i > 0; i--) print lines[i] }' "$path" \
        | while IFS= read -r line; do
            text=$(printf '%s' "$line" | jq -r 'select(.type == "user") | .message.content // empty' 2>/dev/null)
            if [ -n "$text" ] && [ "$text" != "null" ]; then
                printf '%s' "$text"
                break
            fi
        done)

    # Truncate to 60 chars (counted as bytes — fine for our display purpose).
    if [ ${#msg} -gt 60 ]; then
        msg="${msg:0:60}..."
    fi
    printf '%s' "$msg"
}
```

```bash
# Send a macOS notification. Always exits 0.
# Args: <title> <subtitle> <message> <group> <focus_cwd>
send_notification() {
    local title="$1"
    local subtitle="$2"
    local message="$3"
    local group="$4"
    local focus_cwd="$5"

    if ! command -v terminal-notifier >/dev/null 2>&1; then
        echo "cctap: terminal-notifier not found; skipping notification" >&2
        return 0
    fi

    local project_root
    project_root="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

    terminal-notifier \
        -title "$title" \
        -subtitle "$subtitle" \
        -message "$message" \
        -group "$group" \
        -sender "com.warp.Warp" \
        -execute "$project_root/lib/focus_warp.sh '$focus_cwd'" \
        >/dev/null 2>&1 || true

    return 0
}
```

`lib/focus_check.sh`：

```bash
# Check whether the frontmost Warp tab's working directory matches the given path.
# Returns 0 if yes, 1 otherwise. On any failure, returns 1 (treat as "not focused").
is_warp_focused_on() {
    local cwd="$1"
    local script
    script=$(cat <<APPLESCRIPT
try
    tell application "System Events"
        if not (exists process "Warp") then return "no"
        if not (frontmost of process "Warp") then return "no"
    end tell
    tell application "Warp"
        set wd to working directory of selected tab of front window
        if wd starts with "$cwd" then
            return "yes"
        else
            return "no"
        end if
    end tell
on error
    return "no"
end try
APPLESCRIPT
)

    local result
    result=$(osascript -e "$script" 2>/dev/null) || return 1

    [ "$result" = "yes" ]
}
```

`lib/focus_warp.sh`：

```bash
#!/usr/bin/env bash
# Bring the Warp tab matching <cwd> to the front. Falls back to just activating Warp.
# Always exits 0.

focus_warp_tab() {
    local cwd="$1"
    [ -z "$cwd" ] && cwd="/"

    local script
    script=$(cat <<APPLESCRIPT
try
    tell application "Warp" to activate
    tell application "Warp"
        repeat with w in windows
            repeat with t in tabs of w
                try
                    set wd to working directory of t
                    if wd starts with "$cwd" then
                        set index of w to 1
                        set selected of t to true
                        return "matched"
                    end if
                end try
            end repeat
        end repeat
    end tell
on error
    -- best effort: at least bring Warp forward
    try
        tell application "Warp" to activate
    end try
end try
return "done"
APPLESCRIPT
)

    osascript -e "$script" >/dev/null 2>&1 || true
    return 0
}

# When executed (not sourced), call the function with $1.
if [ "${BASH_SOURCE[0]}" = "$0" ]; then
    focus_warp_tab "${1:-}"
fi
```

```bash
#!/usr/bin/env bash
# cctap — Claude Code → macOS notification bridge.
# Contract: exits 0 on every path, never writes to stdout, returns within ~1s.

set +e
trap 'exit 0' ERR

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
LIB_DIR="$PROJECT_ROOT/lib"

# shellcheck source=lib/transcript.sh
source "$LIB_DIR/transcript.sh"
# shellcheck source=lib/notify.sh
source "$LIB_DIR/notify.sh"
# shellcheck source=lib/focus_check.sh
source "$LIB_DIR/focus_check.sh"

log() {
    local cache_dir="${HOME}/.cache/cctap"
    mkdir -p "$cache_dir" 2>/dev/null
    printf '[%s] %s\n' "$(date +%FT%T)" "$*" >> "$cache_dir/cctap.log" 2>/dev/null || true
}

parse_payload() {
    # Echoes <cwd>|<transcript_path>|<message> joined by '|'.
    # Missing/invalid fields become empty strings.
    local input
    input="$(cat)"
    [ -z "$input" ] && { printf '|||'; return 0; }
    printf '%s' "$input" | jq -r '
        (.cwd // "") + "|" +
        (.transcript_path // "") + "|" +
        (.message // "")
    ' 2>/dev/null || printf '|||'
}

handle_stop() {
    local cwd transcript_path _msg
    IFS='|' read -r cwd transcript_path _msg < <(parse_payload)
    [ -z "$cwd" ] && { log "stop: missing cwd"; return 0; }

    if is_warp_focused_on "$cwd"; then
        log "stop: Warp already focused on $cwd, skipping"
        return 0
    fi

    local proj_name summary
    proj_name="$(basename "$cwd")"
    summary="$(extract_last_user_message "$transcript_path")"

    send_notification \
        "${proj_name} · 已完成" \
        "$summary" \
        "Claude 已结束本轮" \
        "cctap:${cwd}" \
        "$cwd"
}

main() {
    local cmd="${1:-}"
    case "$cmd" in
        stop) handle_stop ;;
        *) log "unknown subcommand: $cmd" ;;
    esac
    return 0
}

main "$@"
exit 0
```

```bash
#!/usr/bin/env bash
# Idempotently merge cctap's three hook entries into ~/.claude/settings.json.
# Args: <settings_path> <cctap_bin_path>
set -e

settings="$1"
cctap_bin="$2"

if [ -z "$settings" ] || [ -z "$cctap_bin" ]; then
    echo "usage: merge_hooks.sh <settings.json> <cctap_bin>" >&2
    exit 2
fi

script_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
snippet="$script_dir/hooks-snippet.json"

if [ ! -f "$settings" ]; then
    echo "{}" > "$settings"
fi

# Render snippet with the real cctap path.
rendered=$(sed "s|CCTAP_BIN|$cctap_bin|g" "$snippet")

# Merge per event:
# - Take existing .hooks[event] array (default []).
# - For each entry in the snippet's event array, append it only if no existing
#   entry has a hook with the same command string (idempotency).
merged=$(
    jq --argjson snippet "$rendered" '
        .hooks //= {} |
        reduce ($snippet | to_entries[]) as $kv (.;
            .hooks[$kv.key] //= [] |
            reduce ($kv.value[]) as $newGroup (.;
                ($newGroup.hooks | map(.command)) as $newCmds |
                if (.hooks[$kv.key] | map(.hooks[]?.command) | any(. as $c | $newCmds | index($c) != null))
                then .
                else .hooks[$kv.key] += [$newGroup]
                end
            )
        )
    ' "$settings"
)

printf '%s\n' "$merged" > "$settings"
```

```bash
SETTINGS_FILE="$HOME/.claude/settings.json"
BACKUP_DIR="$HOME/.claude/backups"

backup_settings() {
    [ -f "$SETTINGS_FILE" ] || return 0
    mkdir -p "$BACKUP_DIR"
    local ts
    ts="$(date +%Y%m%d-%H%M%S)"
    cp "$SETTINGS_FILE" "$BACKUP_DIR/settings.$ts.json"
}

handle_install() {
    mkdir -p "$(dirname "$SETTINGS_FILE")"
    backup_settings
    local cctap_bin
    cctap_bin="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/cctap"
    "$PROJECT_ROOT/share/install/merge_hooks.sh" "$SETTINGS_FILE" "$cctap_bin"

    printf "cctap installed.\n\n"
    printf "Permissions reminder:\n"
    printf "  System Settings → Privacy & Security → Automation\n"
    printf "    Terminal/Warp must be allowed to control: Warp, System Events.\n\n"
    printf "Running self-check...\n\n"
    handle_doctor || true
}

handle_uninstall() {
    [ -f "$SETTINGS_FILE" ] || { printf "Nothing to uninstall (no settings.json).\n"; return 0; }
    backup_settings
    local tmp
    tmp="$(mktemp)"
    jq '
        if .hooks == null then . else
            .hooks |= with_entries(
                .value |= map(
                    .hooks |= map(select(.command | test("cctap") | not))
                ) | .value |= map(select(.hooks | length > 0))
            )
        end
    ' "$SETTINGS_FILE" > "$tmp" && mv "$tmp" "$SETTINGS_FILE"
    printf "cctap hooks removed. Run 'brew uninstall cctap' to remove the binary.\n"
}
```

`README.md`：

````markdown
# cctap

Claude Code → macOS 通知小工具。

多个 Claude Code 会话并发跑时，cctap 会在会话**完成一轮**、**等你确认**或**意外退出**时弹出原生通知横幅，点击横幅切回对应的 Warp tab。

## 安装

```bash
brew install jcong830/tap/cctap
cctap install
```

`cctap install` 会：
- 备份 `~/.claude/settings.json` 到 `~/.claude/backups/`
- 追加 cctap 的三个 hook（Stop / Notification / SessionEnd）到 settings.json
- 跑 `cctap doctor` 做环境自检

第一次使用前需要授权：**系统设置 → 隐私与安全性 → 自动化** → 允许 Terminal/Warp 控制 Warp 和系统事件。

## 用法

装完即用，不需要额外配置。CC 会话触发对应 hook 时自动弹通知。

| 命令 | 作用 |
|---|---|
| `cctap doctor` | 检查环境，看依赖和权限是否就绪 |
| `cctap test-notify` | 发一条测试横幅 |
| `cctap install` | 注入 hooks（幂等） |
| `cctap uninstall` | 移除 cctap 的 hooks（不影响其他 hook） |

## 设计要点

- 静默通知（无声音）
- 同一会话的连续通知会替换旧的，不堆叠
- 当前 Warp tab 已经对准会话目录时**不弹通知**
- 所有 hook 路径保证 ≤1s 返回、exit 0、不写 stdout
- 切 tab 是 best-effort（Warp 的 AppleScript 字典随版本变化）

## 排错

```bash
cctap doctor   # 看自检结果和最近日志
tail ~/.cache/cctap/cctap.log
```

## 卸载

```bash
cctap uninstall
brew uninstall cctap
```
````

```ruby
class Cctap < Formula
  desc "macOS notification bridge for Claude Code sessions"
  homepage "https://github.com/jcong830/cctap"
  url "https://github.com/jcong830/cctap/archive/refs/tags/v0.1.0.tar.gz"
  sha256 "REPLACE_ON_RELEASE"
  license "MIT"
  head "https://github.com/jcong830/cctap.git", branch: "main"

  depends_on "jq"
  depends_on "terminal-notifier"

  def install
    libexec.install "lib"
    pkgshare.install "share/install"

    # Patch bin/cctap so PROJECT_ROOT/INSTALL_SHARE point at brew-managed paths
    # instead of resolving via "$(dirname $0)/..". Leaves LIB_DIR="$PROJECT_ROOT/lib"
    # unchanged, which now correctly resolves to #{libexec}/lib.
    inreplace "bin/cctap" do |s|
      s.gsub! 'PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"',
              %Q(PROJECT_ROOT="#{libexec}"\nINSTALL_SHARE="#{pkgshare}/install")
      s.gsub! '"$PROJECT_ROOT/share/install/merge_hooks.sh"', '"$INSTALL_SHARE/merge_hooks.sh"'
    end

    bin.install "bin/cctap"
  end

  test do
    # Smoke: doctor returns 0 when deps are present, and prints expected lines.
    output = shell_output("#{bin}/cctap doctor")
    assert_match "terminal-notifier", output
    assert_match "jq", output
  end
end
```

注：`sha256` 在第一次正式 release 时由 `shasum -a 256 v0.1.0.tar.gz` 算出来再填。`head` 块支持 `brew install --HEAD`，方便开发期不发 tag 也能装。
